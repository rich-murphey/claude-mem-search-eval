# memsearch-en, vector only (exact, and chroma-mem-store, chroma-mem-store-n1000)

memsearch-memory-retrieval, English (machine-translated from Chinese) (zc277584121/memsearch-memory-retrieval @ dbbdc710, MIT); queries and labels generated by gpt-4o-mini. 2172 queries; each searches its project; a document scores as its best part; 95% intervals from 2000 bootstrap resamples over queries. The chroma-mem rows search every document of the dataset in one Chroma collection, with no filter (store mode), asking for 200 parts (n1000: 1,000); minilm-l6 is the exact scoped run.

memsearch answers "does it help in our domain": Claude Code developer memory, Chinese and English, labels generated by gpt-4o-mini. Its recall-based metrics compare models; its P@5 and F1@5 are capped by single-answer queries and are not absolute measures.

Best treated as a measurement of relative accuracy between models, given the label errors discussed in the README ("Caveat on absolute accuracy").
