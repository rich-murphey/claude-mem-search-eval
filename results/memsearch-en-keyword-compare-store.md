# memsearch-en: server keyword search before and after, keyword only, no vectors (store)

memsearch-memory-retrieval, English (machine-translated from Chinese) (zc277584121/memsearch-memory-retrieval @ dbbdc710, MIT); queries and labels generated by gpt-4o-mini. 2172 queries; every document in one claude-mem project, searched by every query; a document is one observation; top 10; no vectors. Runs are described at the top of src/keyword-compare.ts.

memsearch answers "does it help in our domain": Claude Code developer memory, Chinese and English, labels generated by gpt-4o-mini. Its recall-based metrics compare models; its P@5 and F1@5 are capped by single-answer queries and are not absolute measures.

Best treated as a measurement of relative accuracy between models, given the label errors discussed in the README ("Caveat on absolute accuracy").
