# memsearch-zh, vector only (exact, and minilm-l6-split, minilm-l6-128)

memsearch-memory-retrieval, Chinese (original) (zc277584121/memsearch-memory-retrieval @ dbbdc710, MIT); queries and labels generated by gpt-4o-mini. 2172 queries; each searches its project; a document scores as its best part; 95% intervals from 2000 bootstrap resamples over queries. The chroma-mem rows search Chroma 1.4.4 through chroma-mem's bench, each query filtered to its scope by a where, asking for 200 parts and keeping each document's best. minilm-l6-split is the release minilm-l6 vectors with rows over 254 word pieces replaced by chroma-mem's pieces of them; minilm-l6-128 embeds every row and query in chroma-mem (bench load --embed, bench query --embed), split at its piece budget.

memsearch answers "does it help in our domain": Claude Code developer memory, Chinese and English, labels generated by gpt-4o-mini. Its recall-based metrics compare models; its P@5 and F1@5 are capped by single-answer queries and are not absolute measures.

Best treated as a measurement of relative accuracy between models, given the label errors discussed in the README ("Caveat on absolute accuracy").
